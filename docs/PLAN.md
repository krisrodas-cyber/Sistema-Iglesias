# Sistema de Gestión de Iglesias

## Objetivo

Desarrollar un sistema web moderno para la Diócesis de Quetzaltenango.

## Tecnologías

- HTML5
- CSS3
- Bootstrap 5
- JavaScript ES6
- Supabase
- GitHub
- Cloudflare Pages

## Objetivos del proyecto

- Login seguro usando Supabase Auth
- Roles de usuario
- Dashboard principal
- Administración de iglesias
- Administración de sacerdotes
- Administración de usuarios
- Reportes
- Configuración

## Reglas

Todo el código debe estar documentado.

No utilizar jQuery.

Utilizar Fetch API.

Utilizar módulos ES6.

Separar HTML, CSS y JavaScript.

No escribir JavaScript dentro del HTML.

Usar async/await.

El código debe ser limpio y escalable.

Todos los textos estarán en español.

La interfaz debe utilizar Bootstrap 5.

El sistema debe verse profesional.
