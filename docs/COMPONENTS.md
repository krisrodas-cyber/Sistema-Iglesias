# Componentes reutilizables

Todo el sistema debe reutilizar componentes.

No debe existir código duplicado.

## Componentes

Topbar

Sidebar

Footer

Modal

Tabla

Loader

Alertas

## Regla

Si un componente se utilizará en dos o más páginas debe convertirse en un componente reutilizable.

Las páginas nunca deben contener código HTML duplicado de la barra superior ni del menú lateral.

Todo debe cargarse mediante JavaScript utilizando Fetch API.

Los componentes deberán inicializarse automáticamente al cargar la página.
