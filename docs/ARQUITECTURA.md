# Arquitectura del Sistema

# Nombre

Sistema de Gestión de Iglesias
Diócesis de Quetzaltenango

---

# Objetivo

Desarrollar un sistema web moderno, seguro, rápido y escalable para la administración de la Diócesis de Quetzaltenango.

El sistema será completamente responsive y funcionará tanto en computadoras como tablets.

---

# Tecnologías

HTML5

CSS3

Bootstrap 5

Bootstrap Icons

JavaScript ES6

Supabase

Cloudflare Pages

GitHub

---

# Principios

El sistema debe ser:

- Profesional
- Minimalista
- Elegante
- Tecnológico
- Fácil de utilizar
- Muy rápido

No utilizar animaciones exageradas.

Las transiciones deben ser suaves.

Todo debe transmitir confianza.

# Convenciones

Variables en inglés.

Interfaces en español.

Funciones documentadas.

Utilizar módulos ES6.

No escribir JavaScript dentro del HTML.

No utilizar jQuery.

No utilizar código duplicado.

Todos los colores deben declararse mediante variables CSS.

Todo el sistema debe ser responsive.

---

# Seguridad

Utilizar Supabase Auth.

Nunca almacenar contraseñas.

Nunca utilizar LocalStorage para información sensible.

Cerrar sesión destruyendo la sesión de Supabase.

Proteger todas las páginas privadas comprobando la autenticación.

---

# Objetivo visual

Transmitir tecnología, confianza, modernidad y organización.

El diseño debe parecer un software empresarial moderno.
